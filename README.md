# FamCtl — لوحة تحكم أجهزة البيت

ابلكيشن ويب بيشتغل **على الراوتر نفسه** (أو على جهاز لينكس شغال كراوتر للبيت) ويديك من الموبايل أو اللابتوب:

| الميزة | بتشتغل إزاي |
|---|---|
| عرض الأجهزة المتوصلة (اسم، IP، MAC، أونلاين ولا لأ) | من جدول ARP وملف DHCP leases بتاع dnsmasq |
| تحديد سرعة تحميل ورفع لكل جهاز | `tc` HTB على واجهة الـ LAN + جهاز `ifb` للرفع |
| قطع النت عن جهاز بضغطة | `nftables` بيمنع أي traffic من الـ MAC بتاعه |
| قفل مواقع على البيت كله | `dnsmasq` بيرد بـ `0.0.0.0` على الدومين ده |
| قفل مواقع على جهاز معين بس | `dnsmasq nftset` + `nftables` (محتاج dnsmasq ≥ 2.87) |
| منع التحايل بتغيير الـ DNS | كل استعلامات DNS بتتحول للراوتر، و DNS-over-TLS (بورت 853) مقفول |
| تحكم عن بعد في موبايلات أندرويد | ADB Wireless debugging + `scrcpy` (شاشة + ماوس + كيبورد) |

اللوحة عربي وبتشتغل كويس على الموبايل، ومحمية بكلمة سر.

## 1) هتشغله فين؟

راوترات شركات الإنترنت العادية (WE / فودافون / أورنج) **مش بتسمح** إنك تشغل برامج عليها. عندك اختيارين:

- **راوتر بيدعم OpenWrt** (زي كتير من موديلات TP-Link / Xiaomi / GL.iNet): بتسطب OpenWrt وتشغل FamCtl عليه مباشرة. ده أحسن اختيار.
- **Raspberry Pi أو لابتوب قديم بلينكس** بيعمل Wi-Fi access point (hostapd + dnsmasq) والموبايلات تتوصل عليه بدل راوتر الشركة. استخدم `deploy/famctl.service`.

## 2) التسطيب على OpenWrt

```sh
opkg update
opkg install python3 python3-flask tc-full kmod-ifb kmod-sched-core dnsmasq-full nftables
# dnsmasq-full مطلوب عشان قفل المواقع لكل جهاز (nftset)

mkdir -p /opt/famctl && cp -r famctl /opt/famctl/
cp deploy/famctl.openwrt.init /etc/init.d/famctl
vi /etc/init.d/famctl        # غيّر FAMCTL_PASSWORD والسرعة الكلية
chmod +x /etc/init.d/famctl && /etc/init.d/famctl enable && /etc/init.d/famctl start
```

وعلى OpenWrt لازم تضيف السطر ده لإعدادات dnsmasq عشان يقرا ملف FamCtl:

```sh
uci set dhcp.@dnsmasq[0].confdir='/tmp/dnsmasq.d' && uci commit dhcp
```

افتح من أي جهاز على الشبكة: `http://192.168.1.1:8080`

### الإعدادات (متغيرات البيئة)

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `FAMCTL_PASSWORD` | — (إجباري) | كلمة سر اللوحة |
| `FAMCTL_TOTAL_MBIT` | `100` | سرعة النت الكلية عندك بالميجابت |
| `FAMCTL_LAN_IFACE` | `br-lan` | واجهة الشبكة اللي الموبايلات عليها |
| `FAMCTL_ROUTER_IP` | `192.168.1.1` | IP الراوتر |
| `FAMCTL_FORCE_DNS` | `1` | تحويل كل الـ DNS للراوتر |
| `FAMCTL_LEASES` | `/tmp/dhcp.leases` | ملف DHCP leases |
| `FAMCTL_DNSMASQ_CONF` | `/tmp/dnsmasq.d/famctl.conf` | ملف إعدادات dnsmasq اللي بيتولد |
| `FAMCTL_DNSMASQ_RESTART` | `/etc/init.d/dnsmasq restart` | أمر إعادة تشغيل dnsmasq |
| `FAMCTL_DRY_RUN` | `0` | `1` = يطبع الأوامر بس من غير ما ينفذها (للتجربة) |

## 3) خطوة مهمة على كل موبايل

الموبايلات الحديثة بتستخدم **MAC عشوائي (Private / Randomized MAC)** لكل شبكة، وده بيخلي الجهاز يظهر كأنه جهاز جديد وكل الإعدادات تضيع. اللوحة بتعلّم على الأجهزة دي بتحذير أصفر.

- **أندرويد:** الإعدادات ← Wi-Fi ← شبكة البيت ← الخصوصية ← "استخدام MAC الجهاز"
- **آيفون:** الإعدادات ← Wi-Fi ← (i) جنب الشبكة ← اقفل "Private Wi-Fi Address"

وكمان اقفل **Private DNS** في أندرويد (أو سيبها "تلقائي") — FAMCTL بيقفل بورت 853 أصلاً، فلو اتعملت "مزود معين" النت هيقف في الموبايل لحد ما تترجع.

## 4) التحكم عن بعد (أندرويد)

ده بيستخدم أدوات جوجل الرسمية (ADB) ومحتاج **إعداد مرة واحدة على الموبايل نفسه**:

1. الإعدادات ← حول الهاتف ← اضغط على "رقم الإصدار" 7 مرات (بيفتح خيارات المطور).
2. خيارات المطور ← **تصحيح الأخطاء اللاسلكي** ← فعّله ← "إقران الجهاز برمز".
3. في لوحة FamCtl، افتح "تحكم عن بعد" تحت الجهاز واكتب العنوان والرمز اللي ظاهرين ← **إقران**.
4. اكتب العنوان اللي ظاهر في صفحة تصحيح الأخطاء اللاسلكي الرئيسية ← **اتصال** ← **افتح الشاشة**.

`scrcpy` بيفتح شاشة الموبايل في شباك وتقدر تتحكم فيها بالماوس والكيبورد، فلازم يكون FamCtl شغال على جهاز **فيه شاشة** (لابتوب / Raspberry Pi ببيئة رسومية) ومتسطب عليه `adb` و `scrcpy`:

```sh
sudo apt install adb scrcpy
```

لو FamCtl شغال على راوتر OpenWrt (مفيش شاشة)، شغّل `scrcpy` من اللابتوب بتاعك مباشرة:

```sh
adb pair 192.168.1.23:37165     # الرمز اللي ظاهر على الموبايل
adb connect 192.168.1.23:41234
scrcpy -s 192.168.1.23:41234
```

ملاحظات:
- أندرويد بيظهر إشعار ثابت "Wireless debugging connected" طول ما الجلسة شغالة — ده من النظام ومينفعش يتخفى، وده كويس عشان أهلك عارفين.
- بعد ما الموبايل يعمل restart، أندرويد بيقفل Wireless debugging لوحده وبيتغير البورت، فهتحتاج تفعّله تاني.
- **الآيفون مبيدعمش ده.** للآيفون استخدم **Screen Time / Family Sharing** من أبل.
- لو عايز بديل أسهل من ADB: **RustDesk** (مجاني ومفتوح المصدر) أو **Google Family Link** للأطفال — دول بيتسطبوا كأبلكيشن عادي على الموبايل.

## 5) حدود لازم تعرفها

- **قفل المواقع شغال بالـ DNS**: لو حد شغّل VPN على الموبايل هيعدّي من القفل. لو عايز تقفل الـ VPN كمان لازم قواعد إضافية (أو Family Link اللي بيمنع تسطيب أبلكيشنات).
- **القفل لكل جهاز** بيبدأ يشتغل بعد ما الموبايل يسأل عن الموقع من جديد. لو الموقع كان مفتوح قبلها، اقفل الواي فاي وافتحه على الموبايل.
- **تحديد السرعة** بيعتمد على IP الجهاز. لو الـ IP اتغير، دوس "حفظ" تاني أو اعمل للجهاز **Static DHCP lease** في إعدادات الراوتر.
- القواعد بتتطبق تاني لوحدها لما الخدمة تشتغل بعد restart للراوتر.

## 6) تجربته على الكمبيوتر من غير راوتر

```sh
pip install -r requirements.txt
FAMCTL_DRY_RUN=1 FAMCTL_PASSWORD=test FAMCTL_STATE=./state.json python3 -m famctl
# افتح http://localhost:8080
```

في وضع dry-run الأوامر (`tc` / `nft` / `adb`) بتتسجل في اللوج بس.

الاختبارات:

```sh
pip install pytest && python3 -m pytest -q
```

## هيكل المشروع

```
famctl/
  app.py         # Flask: اللوحة و API وتسجيل الدخول
  discovery.py   # اكتشاف الأجهزة من ARP و DHCP leases
  shaping.py     # تحديد السرعة بـ tc
  filtering.py   # قطع النت وقفل المواقع (nftables + dnsmasq)
  remote.py      # ADB + scrcpy
  store.py       # حفظ إعدادات كل جهاز (state.json)
  templates/     # واجهة عربي
deploy/          # ملفات تشغيل الخدمة على OpenWrt و systemd
tests/
```
