Privacy Policy

DATA Conference Manager — DATA Events Solutions. Effective date: 5 October 2026.

1. What the application is

DATA Conference Manager is software installed on the laptops of an event organiser. It stores the event data (attendee names, contact details, professional licence numbers, attendance records and certificates) in a database on those laptops. The data belongs to the organiser.

2. Google account data

The organiser may link a Google account to copy the event data to Google Drive. The application requests only these permissions:

  • Google Drive — files created by this application (drive.file): to create a folder named “DATA Conference Manager” in the organiser's Drive, upload copies of the event data to it, list those copies, download one for import, and delete older copies. The application cannot see or open any other file in the organiser's Drive.
  • Email address (openid, email): to show which Google account is linked.

3. How the data is used and stored

  • Google user data is used only to provide the backup and transfer feature described above.
  • The sign-in token is stored only on the organiser's own laptop. The copies are stored only in the organiser's own Google Drive.
  • No data is sent to DATA Events Solutions or to any third party. The application has no servers of its own and does not use advertising or analytics.
  • Google user data is not sold, shared, or used for advertising, and is not used to develop or train artificial intelligence or machine learning models.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Control and deletion

  • The organiser can unlink the account at any time from the application settings (“Unlink account”), which also revokes the access.
  • Access can also be removed from the Google account at myaccount.google.com/permissions.
  • The copies in Google Drive can be deleted at any time from the “DATA Conference Manager” folder.

1. عن البرنامج

برنامج يُثبَّت على أجهزة الجهة المنظمة للمؤتمر، ويحفظ بيانات المؤتمر (أسماء المشاركين وبيانات التواصل وأرقام القيد والحضور والشهادات) في قاعدة بيانات على تلك الأجهزة. والبيانات ملك للجهة المنظمة.

2. بيانات حساب Google

يمكن للجهة المنظمة ربط حساب Google لنسخ بيانات المؤتمر إلى Google Drive. ويطلب البرنامج الصلاحيات التالية فقط:

  • Google Drive — الملفات التي ينشئها البرنامج فقط: لإنشاء مجلد باسم «DATA Conference Manager» ورفع نسخ البيانات إليه وعرضها واستيراد إحداها وحذف النسخ القديمة. ولا يستطيع البرنامج الاطلاع على أي ملف آخر في Google Drive.
  • البريد الإلكتروني: لعرض الحساب المرتبط.

3. استخدام البيانات وحفظها

  • تُستخدم بيانات Google لتقديم خاصية النسخ والنقل المذكورة فقط.
  • يُحفظ رمز تسجيل الدخول على جهاز الجهة المنظمة فقط، وتُحفظ النسخ في Google Drive الخاص بها فقط.
  • لا تُرسل أي بيانات إلى DATA Events Solutions أو إلى أي طرف ثالث، ولا يستخدم البرنامج أي إعلانات أو أدوات تحليل.

4. التحكم والحذف

يمكن فصل الحساب في أي وقت من إعدادات البرنامج («فصل الحساب») فيُلغى الإذن، أو من صفحة أذونات حساب Google، كما يمكن حذف النسخ من مجلد «DATA Conference Manager» في Google Drive.
